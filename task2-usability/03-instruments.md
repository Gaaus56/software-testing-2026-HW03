Gồm: (A) lời mở đầu và xin đồng ý, (B) phiếu quan sát có cấu trúc, (C) phiếu SUS tiếng Việt, (D) câu hỏi mở, (E) checklist chuẩn bị mỗi phiên.

## A. Lời mở đầu phiên (đọc nguyên văn)

> Cảm ơn bạn đã dành thời gian. Hôm nay mình đang **thử nghiệm một ứng dụng mua sắm**, không phải kiểm tra bạn. Nếu bạn gặp khó khăn thì đó là lỗi của ứng dụng, giúp mình tìm ra chỗ cần sửa. Không có câu trả lời đúng hay sai.
>
> Mình sẽ đưa bạn vài việc cần làm trên điện thoại. Trong lúc làm, bạn cứ **nói to những gì đang nghĩ**: bạn đang tìm gì, thấy gì lạ, thấy chỗ nào khó hiểu. Mình sẽ không hướng dẫn trong lúc bạn làm, vì mình muốn biết ứng dụng tự nó có dễ dùng không.
>
> Mình xin phép **quay lại màn hình điện thoại** (và ghi âm giọng nói) để xem lại sau; video không quay mặt bạn và chỉ dùng cho bài tập này. Bạn có đồng ý không? Bạn có thể dừng bất cứ lúc nào.
>
> Giảng viên/trợ giảng có thể gọi điện cho bạn để xác nhận bạn đã tham gia. Bạn có đồng ý để mình ghi số điện thoại (che 4 số giữa) vào danh sách không?

Ghi lại: đồng ý quay màn hình (Có/Không), đồng ý ghi âm (Có/Không), đồng ý được liên hệ xác minh (Có/Không).

## C. Phiếu SUS (System Usability Scale), tiếng Việt

Chọn mức độ đồng ý: 1 = Hoàn toàn không đồng ý · 2 · 3 · 4 · 5 = Hoàn toàn đồng ý. Giữ nguyên thứ tự 10 câu (câu lẻ tích cực, câu chẵn tiêu cực).

| # | Câu | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| 1 | Tôi nghĩ tôi sẽ muốn dùng ứng dụng này thường xuyên. | | | | | |
| 2 | Tôi thấy ứng dụng phức tạp một cách không cần thiết. | | | | | |
| 3 | Tôi thấy ứng dụng dễ sử dụng. | | | | | |
| 4 | Tôi nghĩ tôi cần người rành kỹ thuật hỗ trợ mới dùng được ứng dụng này. | | | | | |
| 5 | Tôi thấy các chức năng của ứng dụng được kết hợp tốt với nhau. | | | | | |
| 6 | Tôi thấy ứng dụng có quá nhiều điểm không nhất quán. | | | | | |
| 7 | Tôi nghĩ hầu hết mọi người sẽ học dùng ứng dụng này rất nhanh. | | | | | |
| 8 | Tôi thấy ứng dụng rất rườm rà, khó thao tác. | | | | | |
| 9 | Tôi cảm thấy rất tự tin khi dùng ứng dụng. | | | | | |
| 10 | Tôi cần học nhiều thứ trước khi có thể dùng được ứng dụng này. | | | | | |

Tính điểm: câu lẻ (điểm − 1), câu chẵn (5 − điểm), cộng lại × 2.5 → 0–100. Nhập vào [23120017_HW03_SUS.xlsx](23120017_HW03_SUS.xlsx), công thức tự tính. Diễn giải: < 51 kém, 51–68 dưới trung bình, 68 trung bình, > 80.3 tốt (Sauro & Lewis).
